QueryLens — Ask Questions in Plain English, Get Verified Charts

QueryLens lets anyone ask questions about their database in everyday English — like "Show me monthly active users by country" — and turns them into verified SQL, real answers, and visual charts. It checks the SQL syntax before running, fixes mistakes automatically, and remembers previous questions so you don't pay AI costs twice.

Query Lifecycle: Safe Execution Pipeline
01 · INPUT User Question Plain English
→
02 · CACHE Intent Check Instant hit / skip LLM
→
03 · SEARCH Find Tables Pick only needed
→
04 · VERIFY Syntax Check Safe SQL Only
→
05 · OUTPUT Visual Answer Interactive chart

Local Intent Cache

Remembers verified query answers. If a recurring question comes up, it responds instantly without making another remote model call.

Selects Only Needed Tables

Searches the database to find only the 3 or 4 tables needed for the question, keeping context clean and accurate.

Checks SQL Syntax

Verifies SQL with an AST parser before running it. If there is a syntax mistake, it fixes it before touching the database.
